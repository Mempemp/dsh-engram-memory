→
Фильтрпроект воркспейса (COLLATE NOCASE) плюс personal/global; чужие проектные не проходят; удалённые и уже показанные в сессии — тоже

Ход на pre-step: база открыта только на чтение. Сбой любого шага — ход идёт без памяти, без ошибки.

2ЗАПИСЬ — конец хода (push, без модели и без LLM)

События сессииреплика пользователя и ответы модели копятся в буфере хода
→
turn/endход закончился — самое время его разобрать
→
Разбор ходазапрос + изменённые файлы + команды + прочитанное + итоговый текст. Детерминированно, без ключей и сети
→
Триггерсделал (файлы/команды) или выяснил (≥3 чтения/поиска), и итог ≥200 знаков
→
Темапроект/слаг-заголовка — признак пакета работ
→
engram saveасинхронный запуск CLI вне хода; тема уже в сессии — второй раз не пишем

Без изменений и без чтения (разговор, объяснение на словах) запись не создаётся. Тот же разбор повторяется на следующем вопросе как страховка — двойной записи нет.

3ХРАНЕНИЕ — один файл SQLite

%USERPROFILE%\.engram\engram.db  (WAL)
ТаблицаЧто внутриЗачем
observations заголовок, текст, project, scope, topic_key, revision_count, deleted_at, type сами записи; topic_key даёт обновление записи о той же работе вместо дублей (3 записи с одной темой = 1 строка, revision_count 3)
observations_fts FTS5 по заголовку, тексту, типу, проекту, теме русский поиск: кириллица индексируется, регистр складывается, префиксы работают
sessions сессии engram с каталогом воркспейса по ним плагин узнаёт правильное имя проекта для папки воркспейса — иначе запись уезжала в служебный проект
Пишут двоеинструменты MCP — когда модель сохраняет сама (19 инструментов); CLI engram — вызов плагина после хода
Читает одинплагин, readOnly: true — пишущий процесс один, гонок нет
Уровни (scope)project — по умолчанию и всегда у автозаписи; personal — о пользователе; global — конвенции для всех проектов. Общие записи приходят в любом проекте с пометкой ·общее

4ПРАВИЛА — единственное, что живёт в системном промпте

Секция промптаctx.systemPrompt.section, ~1 КБ: память ведётся сама, когда писать global, когда personal, что не сохранять
→
Модельзнает про память без напоминаний и сама зовёт mem_search/mem_save, когда нужно точнее
→
Файлов скиллов нетв десктопной сборке каталог скиллов не читается — правила обязаны ехать внутри плагина
