# engram (vendored MCP server)

Локальная память агента для бандла: одна программа на Go, SQLite + FTS5, интерфейс MCP
по stdio. Ни ключей, ни сети, ни отдельного рантайма.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `engram.exe` | файл из официального релиза, **без изменений** |
| `bin/engram-mcp.js` | прокладка: ставит окружение и прокидывает stdio (см. ниже) |
| `package.json` | только ради `bin` — сид бандла запускает его встроенным Node |
| `LICENSE` | MIT, копия из апстрима |

## Что делает прокладка

Каталожный сид бандла (`installer-catalog-seed.ts`) умеет задать серверу только
`command`/`args`, а окружение сервера санитизируется до вайтлиста. Поэтому команду
собирает сид (встроенный Node + `bin` из `package.json`), а нужные переменные ставит прокладка:

- `ENGRAM_NO_UPDATE_CHECK=1` — апстрим иначе ходит на `api.github.com` при каждом запуске;
- `engram mcp --tools=agent` — 19 инструментов вместо 23, меньше схем в промпте;
- `ENGRAM_DATA_DIR`, `ENGRAM_PROJECT`, `ENGRAM_TIMEZONE` — только если заданы в конфиге.

Профиль инструментов задаётся **аргументом**: переменная `ENGRAM_TOOLS` в engram есть, но
на список инструментов не влияет (проверено на v2.0.0, v2.1.0 и v2.2.0 — 23 инструмента с ней и без неё).
`--tools=agent` даёт 19 во всех трёх версиях; help обещает 18, фактически 19.

Необязательный конфиг (первый найденный путь выигрывает):

1. `$ENGRAM_MCP_CONFIG`
2. `%LOCALAPPDATA%\DSH-1C\engram-mcp.json`
3. `engram-mcp.json` рядом с этим файлом

```json
{ "dataDir": "C:\\Users\\me\\AppData\\Local\\DSH-1C\\engram", "project": "", "tools": "agent", "timezone": "UTC" }
```

Если `dataDir` не задан, engram использует свой дефолт — `%USERPROFILE%\.engram\engram.db`.
Это удобно: тем же стором пользуется CLI и плагин, читающий базу в pre-step.

## Обновление

1. Скачать новый релиз, сверить SHA-256 с `checksums.txt` апстрима.
2. Заменить `engram.exe`, обновить версию и контрольные суммы в этом файле и `version` в `package.json`.
3. `node scripts/prepare-installer-catalog.mjs` — каталог пересоберётся, digest в манифесте изменится.
